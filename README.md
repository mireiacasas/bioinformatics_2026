# Bioinformatics 2026
Material for the bioinformatics course in MBMB-UdG

## The repository contains:

- A markdown example file (markdown_example.md)
- A bash script to create several txt and png files (create_files.sh)
- A folder with several files to practice globbing, created with the previous script (globbing-file)
- A bash script to create a file with sequencing data and random values (create_seq.sh)
- A file with the data created with the previous script (sequencing-data.csv)
- A bash script to create a gff file with random data (genes.sh)
- A gff file created with the previous script (genes.gff)
- A fasta file with several sequences from instuline genes in various species (insulin.fasta)
- A bash script to split a fasta file (split-fasta.sh)
- A readme file (this one)
